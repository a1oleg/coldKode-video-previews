# coldKode — кадры для раскадровки

Публичные скрин-превью авторского видео coldKode2, опубликованные с разрешения
автора для отображения в Google Sheets через IMAGE.

В репозитории только выбранные кадры. Исходное видео, звук, учётные данные
и материалы приватных репозиториев как отдельные файлы сюда не включены.
Номер в имени изображения соответствует строке раскадровки на момент публикации.
